# Fridge-to-Table AI

An AI-powered food management and meal planning application that helps users identify ingredients from fridge images, manage their pantry, and discover recipes based on available ingredients.

## Features

- AI food detection using YOLO-World v2.
- Optional CLIP image refinement.
- Pantry and ingredient management.
- AI-powered recipe generation using Gemini.
- Backup recipe generation using Groq and OpenAI.
- Cuisine-based recipe discovery.
- Recipe details, cooking instructions, and nutritional estimates.
- User registration and login.
- Food management dashboard.

## Tech Stack

- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express
- **AI Detection:** Python, Flask, YOLO-World v2
- **Optional Refinement:** CLIP, Transformers
- **Generative AI:** Google Gemini, Groq, OpenAI
- **Authentication:** JWT, bcryptjs
- **Storage:** Local JSON store

## Installation

### Prerequisites
- Node.js and npm
- Python
- Git
- AI provider API keys

### 1. Clone the repository

```bash
git clone https://github.com/devenn17/fridge-to-table-ai.git
cd fridge-to-table-ai
```

### 2. Install Node dependencies

```bash
npm run install:all
```

### 3. Install Python dependencies

```bash
cd ai-service
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
cd ..
```

### 4. Configure environment variables

Create a root `.env` file:

```env
PORT=5000
GEMINI_API_KEY=your_gemini_api_key
GROQ_API_KEY=your_groq_api_key
OPENAI_API_KEY=your_openai_api_key
```

Never upload your real API keys to GitHub.

## Run the Application

Open three separate terminals from the project root.

**Terminal 1 — Backend**

```bash
npm run dev:server
```

Runs at `http://localhost:5000`

**Terminal 2 — Frontend**

```bash
npm run dev:client
```

Runs at `http://localhost:5173`

**Terminal 3 — AI Detection**

```bash
cd ai-service
venv\Scripts\activate
python app.py
```

Runs at `http://localhost:5001`

## Important Notes

- YOLO-World model weights are not included in this repository. Make sure the required model weights are available before running the detection service.
- CLIP refinement is optional and disabled by default.
- Recipe generation requires a configured AI provider API key.
- Nutritional values generated by AI are estimates.
